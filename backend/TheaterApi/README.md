# TheaterApi

## Pre-requisites

1. .NET SDk (cli tools)
2. Google firebase secret token
3. NeonDB secret Token

## Run Application

Very easy to run.

```bash
dotnet run
```

## Build Application

Same Idea, very easy.

```bash
dotnet build
```
